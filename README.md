# Preparcial Web - Universidad de los Andes

Repositorio para el preparcial de la materia Desarrollo Web.

## Contenido del repositorio

- `preparcial_web.pdf`: Enunciado del preparcial.
- `preparcial/`: Aplicacion web en Next.js 16 que implementa internacionalizacion (i18n), enrutamiento dinamico por prefijo, deteccion por Proxy y persistencia con cookies.

## Ejecucion rapida

```bash
cd preparcial
npm install
npm run dev
```

Para mas informacion sobre la arquitectura y requerimientos, consultar el [README de preparcial](preparcial/README.md).
